# Video Streaming

Tujuan: Mengirim video dari webcam menggunakan libcamera-rs dan GStreamer, kemudian menampilkannya melalui VLC di komputer yang sama atau komputer lain.

Kita akan menggunakan MJPEG terlebih dahulu agar tidak perlu melakukan encoding video H.264.

## Catatan konsep

**Apa itu GStreamer?**
GStreamer adalah framework multimedia untuk membangun pipeline pemrosesan audio dan video.

Contoh pipeline:

```
Camera
  ↓
libcamera
  ↓
FrameBuffer
  ↓
GStreamer
  ↓
Network (UDP)
  ↓
VLC
```

Setiap komponen dalam pipeline disebut element:

| Element   | Funsgi                             |
| --------- | ---------------------------------- |
| appsrc    | Memasukkan data dari aplikasi Rust |
| queue     | Menyediakan antrean buffer         |
| jpegparse | Memproses struktur JPEG            |
| udpsink   | Mengirim data melalui UDP          |
| udpsrc    | Menerima data UDP                  |

**Kenapa UDP?**
UDP mengirim paket tanpa membangun koneksi seperti TCP.

Kelebihannya:

- Latensi relatif rendah
- Tidak perlu retransmission
- Cocok untuk live streaming

Kekurangannya: paket data hilang atau datang tidak berurutan.
